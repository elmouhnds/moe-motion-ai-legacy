# Features (v0.26.0)

**Brand in action** (v0.26.0): Apply Whole Brand (fonts by script + colours by role on the selection or the whole comp, contrast-checked, one Undo), active client in NOW / Design › Brand, brand gradients as Backgrounds presets, Brand ease (docs/features/BRAND_IN_ACTION.md).

**Brand from website / PDF** (v0.25.0): Brand › From website / PDF — colours with roles, fonts matched to installed fonts, gradients, tone, motion feel, rules; review then save (docs/features/BRAND_IMPORT.md).

**Field Effectors** (v0.38.0): two new falloffs — a drifting Noise Field, and Image (the brightness of a logo, gradient or video under each clone is its weight) — for every effector type, with Spring and colour (docs/features/FIELD_EFFECTORS.md).

**Object & Text Cloner** (v0.37.0): Clone on Points puts one copy on each point of a shape (Points layout, Point Offset live); Text Cloner splits a title into one layer per word or letter exactly where it was (In Place layout, Arabic by words), so Effectors, colours and Build animate the words (docs/features/OBJECT_TEXT_CLONER.md).

**Target & Audio Effectors** (v0.36.0): Target turns the clones to face the effector null; Audio drives every move from a soundtrack's loudness (After Effects' Convert Audio to Keyframes, run for you), each clone a little later — tiles Aim, Look Near, Beat Pulse, Beat Wave (docs/features/TARGET_AUDIO_EFFECTORS.md).

**Spring / Inertia Effector** (v0.35.0): effectors move the clones through a damped spring — overshoot and settle, or a smooth Inertia lag at Frequency 0 — live on the effector null (Spring %, Frequency, Decay); tiles Spring Grow, Jelly, Inertia, Bounce Up (docs/features/SPRING_EFFECTOR.md).

**Clone Colours** (v0.34.0): a colour for every clone — Cycle, Gradient or Random from a MOE palette, live on the grid null — and effectors that tint the clones they reach (Colour + Colour Mix) (docs/features/CLONE_COLOURS.md).

**Cloner + Effectors** (v0.33.0): clone one layer into a live grid / ring / spiral / sunflower / globe, then add MOE Effectors — Plain, Random, Step, Noise or Delay with a Sphere, Linear, Box or Everywhere falloff — that move, scale, turn or fade the items near them; up to three per grid (docs/features/CLONER_EFFECTORS.md).

**Library pages** (v0.32.0): settings open where you click (under the row, or beside the tiles from 600 px); Motion shows In · Out · Draw On · Proximity one at a time, Layout shows Arrange · Guides · Cells; tool lists as rows; filters on one line (docs/features/LIBRARY_PAGES.md).

**Space follows content** (v0.31.0): every tab sized by what it holds and merged by job — 25 groups became 15 with the same tools (Animate In / Out / Draw On in one block, Keyframes & Loops, Key & Color, Deliver & Project, Expressions with Sliders); Motion Control compact until keys are selected (docs/features/SPACE_FOLLOWS_CONTENT.md).

**Motion Control** (v0.30.0): the speed / value graph with the anchor point and align beside it, Ease Copy (copy the ease of keys, paste on others), and Next steps after each run (docs/features/MOTION_CONTROL.md).

**Fewer, clearer** (v0.29.0): one place per tool — the Quick Bar holds 41 own actions and any library preset as the tile itself; three styles only (docs/features/FEWER_CLEARER.md).

**Organised the way you work + Assistant** (v0.28.0): Home by how often you use things — Everyday (Alt+1…0), NOW with the comp format, Power tools cards, stages Animate · Arrange · Design · Finish · Deliver — and a floating Assistant that answers and plans (docs/features/WORKFLOW_HOME.md, docs/features/ASSISTANT.md).

**Thick Glass** (v0.27.0): Design › Looks & Glass › Thick — Glaze-class refractive glass from native effects (docs/features/THICK_GLASS.md).

**Three styles** (v0.25.0): Bento (default; pin to NOW, fold sections, scroll-following index) · Glass (Ctrl+1…4, foldable Now, blur switch) · MOE (every shortcut in a sidebar) — docs/features/STYLES_V2.md.

**Three new styles** (v0.24.0, proposals): Glass (frosted cards, four spaces by stage of work, Now card, bottom capsule), Apple (Settings-style lists, coloured icons, categories you open), Bento ★ (one page, tile size = importance, the big tool for the selection on top). ≡ › Panel layout / Settings › New styles (docs/features/STYLE_PROPOSALS.md).

**Design system** (v0.23.0): one scale for controls (24 · 28 · 32), icons (12 · 14 · 16 · 20) and corners (6 · 8); tools by importance in every group (primary first and larger, rare ones as chips); Lucide for generic icons, MOE icons for motion; quiet links, elevated menus, moving Out thumbnails (docs/features/DESIGN_SYSTEM.md).

**Classic groups** (v0.22.0): drag a group's header (or Alt+↑/↓) to reorder — saved per tab, ▾ › Reset group order; ▸ Recent in every tab (last six things you ran there, fixed-height row); ↑/↓ ←/→ on group headers.

**Final layout** (v0.21.0): Classic is the final panel layout (docs/features/FINAL_LAYOUT.md). Each tab has a ▾ quick menu (or right-click the tab) with all its actions and presets; Ctrl 1…6 switch tabs. MOE ★ (object menus on top of Classic) stays optional; Hub / Command Bar / Workspace retired from the lists.

**Classic layout** (v0.20.0, default): tabs named after AE's menus (Keys · Animate · Layer · Design · Effect · Comp), twirl-down groups like Effect Controls, search like Effects & Presets, ≡ panel menu, one-click preset tiles, smart dots / auto-open groups for the selection.

**Grid Builder 2** (v0.19.0): Layout switches live in Effect Controls (all controls and keyframes stay), Morph To + Morph slider (animate at build), Orient (Forward / Face Center / Face Screen), Effector scale / push / attract / rotate / fade, items stay editable by hand, Grid Items (drag / sort places without touching the layer stack, per-item Twist and Delay), and a "Your grid" panel when a grid is selected. Palette tiles in Backgrounds move on hover with your motion.

**Moving backgrounds** (v0.18.0): Backgrounds › Motion (Drift, Orbit, Swirl, Wave, Breathe, Wander) and Colours (Cycle, Swap, Hue, Pulse) — expressions on the gradient points and colours, seamless loops, live sliders MOE BG Loop / Amount / Colour, live preview in the Inspector.

**★ MOE layout** (v0.17.0, recommended): menus by object (lit for the selection) + your Quick Bar + four stable task tabs — Settings › Panel layout › MOE ★.

**Panel layouts** (v0.16.0): Settings › Panel layout — Current · **Hub** (screens + fixed Home + *For this* strip) · **Command Bar** (menus by object, highlighted for the selection + your bars) · **Workspace** (context bar + four stable task tabs + your bar). Every tool keeps one place; context areas only copy (docs/features/UI_LAYOUTS.md).

**Smart Home** (v0.15.0): the selection decides the focus card (keys → ease + keys + loops; layer → animate in/out + rigs + anchor/align; layers → cascade + arrange + link; text → text in; shapes → draw + arrange; nothing → create); stable zones Focus → Your tools → More → Recent; folds remembered per kind of selection; Layout: fixed for the old order.

**A curve for each segment** (v0.14.0): with 3+ keys, pick a segment in the strip or the overview and the graphs edit only it; All = one curve everywhere. **Tidier panel**: foldable kit blocks, grouped Toolbox, Quick Bar that fits one row with +N, *Utilities* instead of *Tools*.

**Ease graphs** (v0.13.0): Value + Speed together, both draggable and synced (hover shows the same moment on both); Alt + wheel fine-tune; Flip; presets are curve pictures only (+ saves without a name, removable with undo). **Align**: ↔ / ↕ rows, Space evenly with equal or fixed gaps, align to Selection · Key layer · Comp (Alt = comp, Shift = key).

**Delay = Cinema 4D** (v0.12.0): Even · Blend · Spring like C4D's MoGraph Delay effector, plus **Field (null)** — a null sets each layer's delay by distance (radius, falloff, invert; move it to sweep, scale it to grow).

**Free drag on the ease graph** (v0.11.1): press anywhere and drag, like Motion 4 — left = start (ease out), right = end (ease in), middle = both mirrored; sideways = influence, up / down = shape or speed; Shift fine, Ctrl snap; handles still grab directly.

**Delay** (v0.11.0): Cinema 4D MoGraph Delay for layers — Spring / Blend / Offset on a layer's own animation, or followers trailing the first selected layer, live sliders. **Speed graph**: real units (px/s, °/s, %/s), velocity fields (AE Keyframe Velocity), whole-animation overview, pass-through middle keys.

**Motion Kit** (v0.10.0 — on **Home** first: ease · anchor · align · pinned tools; all tools + curve library in the **Toolbox**, Ctrl 2; also *Window › Extensions › MOE Motion Kit*): ease graph that reads the selected keys and applies on release · preset chips (click; Shift in / Ctrl out) · Easy Ease / Linear / Hold / Copy / Paste · 3 × 3 anchor (Alt: place in comp) · align / distribute row · 18 one-click tools (Null, Parent, Excite, Jump, Orbit, Spin, Swing, Wiggle, Stare, Clone keys, Reverse, Stagger, Trim to keys, Separate, Trim path, Repeat, Vignette, Trash). Study and design: docs/features/MOTION_KIT.md.

Motion-4-style tools (v0.9.0): **Ease Curves** — drag a Bézier on the value graph (live speed graph), 32 curves, applied as exact speed + influence between selected keyframes, read from keys · **Anchor & Align** — anchor to 9 points without a jump, align / distribute to selection or comp, clone into ring / fan / row / grid · Quick Bar group *Align* · new pie slots.

Navigation (v0.8.0): Home + five workspaces (Animate · Design · Layout · Finish · Tools) with section tabs · Pie menu (hold Q or the right button; smart slices by selection or My pie; centre = repeat) · Home "For this selection".

Workflow (v0.7.0): sticky Apply bar in every library and Text · ▶ on every tile · tiles dimmed with the reason when the selection cannot run them · F4 / ↻ repeat last change · Ctrl K finds and applies presets (Enter) · grouped sidebar with hideable sections · Compositing as a tile library · banners shown in full once · compact tiles in narrow panels · Home puts Recent / Favorites first for returning users.

Install & updates: Windows Setup.exe (in place, no admin) + Settings › Updates — see INSTALL.md.
