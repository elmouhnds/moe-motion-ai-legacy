Settings

v13

Adjust dock behavior, open another panel and find the preferences for an individual tool.

Click Settings, the gear in the top bar. The dock opens a separate settings window. Choose Motion Dock for dock preferences, or a tool’s name for that tool’s settings.

On a narrow settings window, use the menu button to open the section list. Changes save as you make them. Close the window or press Escape when finished.

Dock preferences

SettingDefaultEffect
Spacing5px.The space between your tools and between the buttons inside them, from 2 to 10 pixels. Every tool follows it, so the whole dock stays even.
Keep modules fixedOn.Moving or resizing a slot does not push neighboring slots. Turn it off to allow that movement.
Warn when offlineOn.Show No internet connection. when the dock detects that the computer is offline. Turning it off hides the warning.

Spacing changes the whole dock at once. The gaps between your tools and the gaps between the buttons inside them always match, and the tools rearrange themselves to fit.

These preferences are shared across dock panels. The dock follows After Effects’ light or dark appearance automatically.

Import / Export

Export setup… saves one .motiondock file with all five panels’ layouts, tool settings, AEbar bars and their scripts, presets and icons, library notes and their images, Petals palettes, dock images and your Atom tools. Logs, update downloads and credentials stay on this computer. Notes and palettes saved inside an After Effects project stay with the .aep file.

To move it by hand, save the backup anywhere you can reach from your other computer. There, open the Motion Dock’s settings and choose Import setup…. To keep two computers matched on their own, use Sync.

Import checks the file before asking Import this setup? Choose Import to replace your layouts, settings and libraries and reload the open dock panels and settings or editor windows. Export the receiving computer’s setup first if you want to keep a copy.

If this computer has Atom tools that aren’t in the file, Keep existing Atom tools appears with a short explanation and the actual count. It starts on. Leave it on to keep those tools and their settings, or turn it off to remove them. Tools included in the import are added or updated.

Already-missing AEbar files and note images are named after export so you can find them. Project layout memories carry over when the .aep paths match. The backup does not move project files, install fonts or plugins, or change paths written inside your own scripts.

Sync

Choose sync folder… keeps your setup in a folder you pick, such as one in iCloud Drive, Dropbox, OneDrive or Google Drive. The folder holds one file, Motion Dock Setup.motiondock, with the same contents as Export setup…. Your cloud app copies it between your computers. The Motion Dock never uploads anything itself.

On your first computer, choose an empty folder and the dock saves your setup there. On your other computer, choose the same folder. The dock asks Use the setup in this folder? Choose Use it to replace that computer’s layouts, settings and libraries with it. Keep existing Atom tools works the same way as it does for Import.

From then on, a change on either computer is saved to the folder a moment later. When the file changes from your other computer, the open dock loads it and reloads its panels. If both computers changed before the folder caught up, the newer change wins.

Scripts, presets and icons behind your AEbar buttons travel inside the file. The computer they came from keeps using its own files, and your other computer gets copies. Logs, update downloads and credentials stay on each computer.

The settings show the folder while it syncs. Stop syncing stops using it and leaves the file where it is. If the folder goes missing, or iCloud hasn’t downloaded the file yet, the dock tells you.

Tool settings

The sidebar lists the tools with settings. These preferences are shared across copies of a tool in the dock. Each tool’s own docs cover its settings, labels and defaults.

You can go straight to a tool’s section from layout mode. Select it and click Module settings, double-click its slot, or right-click and choose Module settings. Tools with no settings do not have a settings section to configure.

Loading settings… appears while a tool’s preferences load. No settings available for this module. means the selected section has no settings to show.
