Controls and shortcuts

v13

Look up dock controls, picker actions and keyboard shortcuts in one place.

Top bar

ControlAction
1, 2, 3Switch to that layout. An empty layout’s number is dimmed.
Edit layoutOpen the grid for arranging tools and elements.
Exit layout modeLeave layout mode and return to using tool controls.
SettingsOpen dock and tool settings in a separate window.

Selected slots in layout mode

Select a slot to show its controls in the top bar.

ControlAction
Module colorOpen the selected slot’s accent picker.
DocumentationOpen the selected tool’s documentation.
Module settingsOpen the selected tool’s settings, when it has them. Double-clicking the tool also opens settings.
BarFor AEbar, choose which bar the selected copy shows.
RemoveRemove the selected slot from the active layout.
Edit text, AlignmentFor Text, edit its words or cycle left, center and right alignment.
Choose image, Fit or fillFor Image, replace its picture or switch between fitting and cropping it.

Clear layout 1, Clear layout 2 or Clear layout 3 appears in layout mode when the active layout contains slots. It asks to remove every tool and element from that layout.

Panel menu

Click ≡ beside the panel’s name in its tab. An isolated panel has no top bar, so this menu holds its controls.

ItemAction
Layout 1, Layout 2, Layout 3Switch to that layout.
Edit LayoutEnter or leave layout mode.
Settings…Open dock and tool settings.
Isolate PanelShow only this panel’s tools, edge to edge, or bring the top bar back.

Grid and picker

ActionResult
Click empty grid space in layout mode.Open the picker at that position.
Draw a rectangle in empty grid space.Open the picker with a chosen starting shape.
Drag a slot or one of its edges or corners.Move or resize it.
Right-click a slot in layout mode.Open its settings or content action, color and removal menu.
Type in Search tools.Filter tools and elements by name, description or group.
Click a picker card.Add it, unless it is marked Already in this layout.
Click About beside a picker entry’s name.Read its description and see its preview, add button and tool documentation link.
All toolsLeave the detail view.
CloseCancel the picker.

For placement, sizing and removal details, use Add, move and resize tools. The personalization guide covers color and element controls.

Keyboard shortcuts

The dock must have focus. Layout switching and layout undo pause while you type in a field or have a dock dialog open.

KeyAction
1, 2, 3Switch layout. Use the number row.
Cmd/Ctrl+ZIn layout mode, undo a layout edit.
Cmd/Ctrl+Shift+ZIn layout mode, redo a layout edit.
EnterIn picker search, add the best matching entry that can still be added.
EnterIn a picker detail view, add the shown entry if available.
EscapeIn a picker detail view, return to the list. In the list, cancel the picker.
Enter / EscapeWhile editing a Text element, save / cancel the edit.
EnterIn a valid Hex color field, commit the color and close the picker.
EscapeIn the color picker, restore the color present when it opened.
EscapeClose the settings window.

Each tool’s own docs cover its modifier keys.
