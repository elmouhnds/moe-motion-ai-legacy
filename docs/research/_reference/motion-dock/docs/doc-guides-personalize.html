Add colors, labels and images

v13

Give slots their own colors and use text, dividers and pictures to organize a layout.

Enter Edit layout first. Colors and elements belong to their slots, so you can arrange them alongside your tools.

Choose a slot color

Select a slot and click Module color, the color dot in the top bar. You can also right-click a tool and choose Module color, or right-click an element and choose Color.

Hover a preset to preview it on the slot. Click to keep it. Default returns to the theme’s accent color. For a custom color, open Custom, drag Hue or enter a value in Hex color. Press Enter to confirm a valid hex value and close the picker.

Clicking outside the picker keeps the last committed color. Escape restores the color from when you opened it. One picker session is one layout undo step.

Add a label

Click or draw in an empty part of the grid, then choose Text from Elements in the picker. Type a label and press Enter, or click away to save it. Escape cancels the text edit.

Double-click a label in layout mode to edit it again. You can also select it and click Edit text in the top bar, or right-click and choose Edit text.

Use Alignment in the top bar to cycle through left, center and right alignment. Increase the slot’s height to increase the text size. Give long labels more width to avoid clipping.

Separate groups

Add Divider from Elements. A wide slot makes a horizontal rule; a tall slot makes a vertical one. Its line uses the slot’s color.

Add a picture or GIF

Add Image from Elements, then choose a PNG, JPG, GIF or WebP. PNG transparency is kept, and animated GIFs keep playing.

The dock stores its own copy of the file. Moving the original does not break the image. Select the slot and use Choose image, or double-click it in layout mode, to choose another file.

Fit or fill switches between showing the whole image and filling the slot with a crop. Fit is the default. Resize the slot to choose its shape.

If you cancel the file picker when adding an image, the slot stays empty. Select it and use Choose image when you are ready. Read image troubleshooting if the slot displays an error.

Select an element and click Remove, or right-click it and choose Remove. Elements use the same layout undo as tool slots.
