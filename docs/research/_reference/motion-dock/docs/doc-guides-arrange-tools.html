Add, move and resize tools

v13

Build a layout around the tools you use and recover layout changes with Undo and Redo.

Click the grid button labelled Edit layout in the dock’s top bar. A dotted grid appears, and tool controls give way to selecting, moving and sizing their slots.

If the layout is empty, Click or drag to add a module shows where to begin. The grid keeps going past the bottom of the panel, so scroll down whenever you need more room.

Add a tool

  1. Click an empty part of the grid. To choose the size first, drag a rectangle across empty space instead.
  2. Type a name or task into Search tools, or browse the groups.
  3. Click a tool’s card to add it. For a closer look, click About beside its name, then Add followed by the tool’s name.

The information view includes a Documentation button for the tool’s full guide. All tools returns to the picker. Close cancels without adding anything.

A click on the grid starts with the tool’s usual size. A drawn rectangle starts with that shape. The dock fits the new slot into the available space, so it may be smaller than the area you first chose.

A box is drawn in the dock, the tool library opens, and Petals lands in the box.

If the picker will not add a tool

Most tools allow one copy per layout. A check mark and Already in this layout mean that tool is present, even if it is farther down the dock. Move or resize the existing copy, or use a different layout.

AEbar, Noted and Petals allow multiple copies. Text, Divider and Image elements also allow multiple copies.

Choose a bar for AEbar

When you add AEbar, it opens its list of bars right away. Pick the bar this copy should show, or choose New bar to start an empty one. Each AEbar copy can show a different bar.

To change it later, select the AEbar slot and click Bar in the top bar, or right-click it and choose Bar.

If the picker says No tools match followed by your search, shorten or clear Search tools. Search checks names, descriptions and groups.

Move and resize

Drag a tool’s slot to move it. Drag any edge or corner to resize it. Both actions snap to the grid. The grid has 16 columns, with rows 25 pixels high. Columns grow or shrink with the panel’s width.

Try a wide, short slot for a toolbar or a taller slot for a tool you use in more depth. Individual tools choose their own layout based on the space they receive. Their own docs explain size-dependent controls.

By default, other tools stay in place while you move or resize a slot. Turn off Keep modules fixed in Settings if you want neighboring tools to move out of the way.

Remove a tool or leave it out

Select a slot, then click Remove in the top bar. You can also right-click a tool and choose Remove module. The removal notice includes Undo.

Removing a slot takes it out of this layout. You can add it again through the picker. There is no need to include every tool in every layout.

To empty the whole active layout, click Clear layout 1, Clear layout 2 or Clear layout 3 in the top bar and confirm Clear. This removes its tools and elements, keeps tool settings and returns to the starter choices. The notice includes Undo.

Undo layout changes

While in layout mode, press Cmd/Ctrl+Z to undo and Cmd/Ctrl+Shift+Z to redo. This covers adding, removing, moving, resizing, slot colors and element edits. Each of the three layouts has its own history.

A new edit clears the redo history for that layout. History lasts for the current panel session. It is separate from After Effects’ timeline undo.

Click Exit layout mode to use the tools again. The dock saves layout edits automatically.
